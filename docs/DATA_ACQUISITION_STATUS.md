## 2. Status Definitions

| Status | Meaning | Next Action |
|--------|---------|-------------|
| `NOT_STARTED` | Acquisition not yet attempted | Assign owner; schedule download |
| `DOWNLOADING` | In progress | Monitor; verify completion |
| `DOWNLOADED` | File on disk | Run `register_file` + `validate_raw` |
| `VALIDATED` | Passed all quality gates | Ready for ingestion |
| `QUARANTINED` | Failed validation | Investigate; document; re-download or patch |
| `INGESTED` | Loaded to canonical tables | Update `dataset_registry`; verify counts |
| `NOT_CONFIGURED` | Requires credentials/API access | Track credential request; use fixtures meantime |
| `DEPRECATED` | Superseded by newer version | Archive; do not ingest |

## 8. Update Procedure

**On every file acquisition:**
1. Save file to `data/raw/<source>/<YYYYMMDD>/<original_filename>`
2. Run: `python -m labrex.data.register_file --source SRC-XXX --dir data/raw/xxx/YYYYMMDD/`
3. Run: `python -m labrex.data.validate_raw --source SRC-XXX --dir data/raw/xxx/YYYYMMDD/`
4. Update this file: add row to Master Tracker with SHA-256, size, status
5. If `VALIDATED`: proceed to ingestion per `INGESTION_ROADMAP.md`
6. If `QUARANTINED`: document issue in Known Issues; do not ingest

**Weekly Review:**
- Update Progress Summary counts
- Escalate Critical Path items past target date
- Archive DEPRECATED artifacts (move to `data/archive/`)
